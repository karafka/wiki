# Upgrading to Web UI 0.3

Because of the removal of compatibility fallbacks for job and process tags (from the old 0.1.x report format), it is recommended to:

- First, deploy **all** the Karafka consumer processes (`karafka server`)
- Deploy the Web update to your web server.

Note that if you decide to use the updated Web UI with not updated consumers, you may hit a 500 error.
